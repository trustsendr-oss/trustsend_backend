# Moyens de paiement

Avant d'initier un dépôt ou un retrait, récupérez la liste des opérateurs disponibles pour la devise concernée. Pour chaque opérateur, vous obtenez le code à transmettre dans le champ `provider`, sa disponibilité en temps réel et les montants acceptés.

<div className="ts-endpoint">
  <span className="ts-endpoint__label">GET</span>
  <span className="ts-endpoint__url">{'/api/v1/business/mobile-money/payment-methods'}</span>
</div>

| Paramètre | Emplacement | Requis | Description |
|---|---|---|---|
| `currency_code` | Query | Oui | Code de devise ISO 4217, par exemple `CDF` |
| `operation_type` | Query | Non | `DEPOSIT` (par défaut) ou `PAYOUT` |

```bash
curl "https://api.trustsend.africa/api/v1/business/mobile-money/payment-methods?currency_code=CDF&operation_type=DEPOSIT" \
  -H "Authorization: Bearer $TRUSTSEND_API_KEY"
```

**Réponse `200`**

```json
{
  "data": [
    {
      "provider": "VODACOM_MPESA_COD",
      "display_name": "Vodacom M-Pesa",
      "status": "OPERATIONAL",
      "min_amount": "500",
      "max_amount": "500000000"
    }
  ]
}
```

| Champ | Description |
|---|---|
| `provider` | Code opérateur à utiliser lors d'un dépôt ou d'un retrait |
| `display_name` | Nom de l'opérateur, à afficher à vos clients |
| `status` | `OPERATIONAL` lorsque l'opérateur accepte les opérations ; toute autre valeur signale une indisponibilité temporaire |
| `min_amount` | Montant minimal accepté, en centièmes de la devise |
| `max_amount` | Montant maximal accepté, en centièmes de la devise |

:::tip
Interrogez cet endpoint au moment d'afficher le choix de l'opérateur à votre client, et n'initiez pas d'opération vers un opérateur dont le statut n'est pas `OPERATIONAL`.
:::

:::note
Nécessite la fonctionnalité `mobile_money.toolkit` dans votre offre.
:::
