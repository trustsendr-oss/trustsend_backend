# Webhooks — notifications sortantes (Business)

Différent des [notifications in-app](/business/overview) : ceci envoie une requête HTTP vers **votre propre serveur** à chaque événement.

## `GET /api/v1/business/webhooks` (ou `/business/dashboard/webhooks`) 🔒
```json
{ "data": [ { "id": 3, "url": "https://maboutique.com/webhooks/trustsend", "events": ["mobile_money_deposit.completed"], "active": true, "created_at": "..." } ] }
```

## `POST /api/v1/business/webhooks` 🔒
**Body**
```json
{
  "url": "https://maboutique.com/webhooks/trustsend",
  "events": ["mobile_money_deposit.completed", "mobile_money_payout.failed"]
}
```
`events` possibles : `mobile_money_deposit.completed`, `mobile_money_deposit.failed`, `mobile_money_payout.completed`, `mobile_money_payout.failed`.

**Réponse `201`**
```json
{
  "data": {
    "url": "...", "events": [...], "active": true,
    "secret": "whsec_...",
    "message": "Webhook subscribed. Store the secret securely — used to verify X-Webhook-Signature on delivery."
  }
}
```
⚠️ `secret` n'est renvoyé qu'à la création — sert à vérifier l'en-tête `X-Webhook-Signature` (HMAC) sur chaque livraison reçue.
