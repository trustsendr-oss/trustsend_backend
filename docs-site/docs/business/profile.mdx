# Profil — Business

## `GET /api/v1/business/dashboard/profile` 🔒

**Réponse `200`**
```json
{
  "data": {
    "id": 55,
    "code": "MABOUTIQUE",
    "name": "Ma Boutique SARL",
    "email": "contact@maboutique.com",
    "phone": "260763456789",
    "status": "active",
    "webhook_url": null,
    "pin_set": true,
    "created_at": "2026-08-30T08:03:02.227+00:00"
  }
}
```

`pin_set` indique si le frontend doit afficher l'écran "Configurer votre PIN" (voir [PIN](/business/pin)).

## `PATCH /api/v1/business/dashboard/profile` 🔒

**Body** (tous les champs optionnels)
```json
{ "name": "Ma Boutique SARL v2", "phone": "260763456780", "webhook_url": "https://maboutique.com/hook" }
```

:::warning
`email` n'est **volontairement pas modifiable** ici — un changement d'email reste une action admin, pour éviter qu'un token dashboard compromis serve à rediriger silencieusement la récupération de compte.
:::

**Réponse `200`**
```json
{ "data": { "id": 55, "name": "Ma Boutique SARL v2", "phone": "260763456780", "webhook_url": "https://maboutique.com/hook", "updated_at": "..." } }
```
